# Pin / Tone

`Pin::tone(freq)` / `noTone()` — генерация тона (меандр ~50%) через LEDC на
GPIO13. До 2026-11-08 пример был копией старого interrupt-каркаса (issues.md #26) —
переписан по назначению.

## Что демонстрирует

Две формы `tone` (`include/async/Pin.h`):

| Форма | Поведение |
|---|---|
| `tone(freq, Duration)` | Прозвенит заданное время и замолкнет сам (одноразовая Active-задача остановки). До фикса #9 (2026-11-09) каждый вызов течёт (~173 Б); теперь задача освобождается после срабатывания — **указатель на неё при этом невалиден**. |
| `tone(freq)` + `noTone()` | Ручной старт/стоп — без утечек. |

Цикл примера (фазы по 2 с): boot-beep 600 Гц/1.5 c → 440 Гц → тишина →
1000 Гц → тишина → …

## Отчёт о проверке

- **Дата:** 2026-11-08
- **Стенд:** DUT `esp32dev` (COM11) + стимулятор ESP32-C3 (COM12, см.
  `auxiliary/`): GPIO13 DUT соединён с каналом 4 (C3 GPIO6); команда `FREQ`
  превращает C3 в частотомер (подсчёт rising-фронтов, пин hi-Z) — частоты
  измерены независимо от DUT
- **Фреймворк:** Arduino-ESP32 **3.3.5**, ESP-IDF **5.5.1** (`pioarduino#55.03.35`)
- **Результат: OK.** На линии подтверждён настоящий меандр с точными частотами:

| Фаза примера | Заявлено | Измерено C3 |
|---|---|---|
| boot beep (форма с duration) | 600 Гц, 1.5 c | **600 Гц** (240 фронтов / 400 мс), сам замолк к ~1.9 c |
| `tone(440)` | 440 Гц | **437 Гц** (175 / 400 мс) |
| `tone(1000)` | 1000 Гц | **1000 Гц** (500 / 500 мс) |
| `noTone()` | тишина | **0 Гц**, линия прижата LOW (`ledc_stop(..., 0)`) |

```
I (8)    MAIN: boot beep: tone 600 Hz for 1500 ms
I (2138) MAIN: TONE 440 Hz
I (4136) MAIN: SILENCE
I (6138) MAIN: TONE 1000 Hz
I (8136) MAIN: SILENCE
FREQ ch4: 600 Hz (240 edges / 400 ms, lvl 0..1)
FREQ ch4: 437 Hz (175 edges / 400 ms, lvl 0..1)
FREQ ch4: 1000 Hz (500 edges / 500 ms, lvl 0..1)
```

- Форма `tone(freq, duration)` подтверждена: boot-beep остановился сам (фаза 440
  началась на чистой линии). Регресс после фикса #9 (2026-11-09): timed-форма
  больше не течёт, частоты те же (440/1000 Гц перепроверены C3).

## Сборка и прошивка

```bash
pio run -e pin_tone -t upload
PYTHONIOENCODING=utf-8 pio device monitor -p COM11
```
