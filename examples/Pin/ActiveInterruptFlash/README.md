# Pin / ActiveInterruptFlash

Стресс-тест фикса issues.md **#5**: активное прерывание во время flash-операций
(NVS-записи отключают кэш — до фикса ISR во flash давал Guru Meditation).

Автономный: фронты на pin14 даёт плата-стимулятор (изначально — перемычка 27→14,
теперь канал 1:GPIO3→14, перемычка снята), фоновая задача молотит NVS (~1000
записей/с). «Если чип жив» — раз в секунду печатается `alive` со счётчиками фронтов.

## Отчёт о проверке

- **Дата:** 2026-11-08
- **Стенд:** DUT `esp32dev` (COM11) + стимулятор ESP32-C3 (COM12, см. `auxiliary/`);
  фронт-поток — меандр 50 мс (~10 Гц) каналом 1:GPIO3→14; перемычка 27→14 снята
  (её функцию выполняет стимулятор)
- **Фреймворк:** Arduino-ESP32 **3.3.5**, ESP-IDF **5.5.1** (`pioarduino#55.03.35`)
- **Результат:** OK по назначению теста: 12 с под двойной нагрузкой (10 Гц фронтов +
  NVS) — **ни одного краша/abort/backtrace** (фикс #5: ISR-цепочка в IRAM — держит).
  `alive` печатается каждую секунду, планировщик жив.
- **Попутно воспроизведён (и в тот же день исправлен) баг #3** — окно ре-арма:
  ДО фикса на ~8-й секунде непрерывных 10 Гц фронтов пин замолкал — счётчики
  вставали на FALLING=54 RISING=51 (фронт в окне [`gpio_intr_enable` …
  `interrupted=false`] → ISR дропал заявку при `interrupted==true`, прерывание
  оставалось выключенным навсегда; чип при этом жив — `alive` продолжал печататься).
  **Фикс #3 (2026-11-08):** в `Pin::onDemand` порядок изменён на
  `interrupted=false` → `gpio_intr_enable` → колбэки. После фикса: 39 с на 10 Гц —
  счётчики растут линейно до **FALLING=357 RISING=360**, заморозки нет; отдельно
  проверен дребезг (см. README ActiveInterrupt).

```
I (3145) MAIN: alive: FALLING=8 RISING=7      <- лог ДО фикса #3 (2026-11-08, утром)
I (8145) MAIN: alive: FALLING=54 RISING=51   <- далее счётчики замерли: mute-окно #3
I (10145) MAIN: alive: FALLING=54 RISING=51  <- чип жив, пин глух (тогда — open #3)
...
I (38145) MAIN: alive: FALLING=348 RISING=350 <- ПОСЛЕ фикса #3: 39 с, рост линейный
I (39145) MAIN: alive: FALLING=357 RISING=360
```

## Сборка и прошивка
